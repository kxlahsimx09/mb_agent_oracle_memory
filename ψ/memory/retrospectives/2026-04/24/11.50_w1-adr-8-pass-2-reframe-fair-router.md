## AI Diary

This pass had a structure unlike any I've run. Pass 1 was "elevate a pattern from lane-local to cross-cutting." Pass 2 was "invert the primary decision based on evidence that should have been read before pass 1 shipped."

The mechanics of how we got here are worth recording, because they're going to recur.

I started pass 1 believing §ADR-4a's pull-first decision was load-bearing enough to elevate. I was right about the elevation value but wrong about the primary claim. The mistake was subtle: I characterized current-system fairness as "statistical / weak" without doing Input 5 to verify. Oracle learnings described **what** `findBestBankForItem` does ("spreads items across banks") — not **how** (least-daily-count LRU selection). That gap was enough for me to plausibly assume pull's statistical fairness was parity, when it's actually a regression.

User caught this in the second exchange. "ความจริง เรายังต้องการที่จะคุม (กระจาย transaction ถอน) ให้เท่าๆ กัน" — that's the moment the pass-1 framing cracked. ## Meta-pattern captured — reframe-via-Input-5 after user-surfaced axis

This pass is a canonical shape of the "review-driven pass cadence" pattern that the session-closeout retro of 2026-04-23 flagged. The specific mechanism is worth naming:

```
Pass N (provisional) → user surfaces axis that pass N didn't weight
→ architect responds with options under the new axis (assuming prior-art is accurate)
→ user asks targeted question that tests architect's prior-art assumption
→ architect hedges (signals the assumption is unverified)
→ user directs Input 5
→ Input 5 finding inverts or reshapes primary decision
→ pass N+1 (provisional) supersedes pass N with new decision
→ thread-first discipline means no downstream work built on pass N's wrong claim
```

This pattern is the exact inverse of "confidently shipping wrong." It's "uncertainly shipping provisional, iterating on the uncertain parts." The tags (`#provisional`, `[RATIFICATION_PENDING]`, `[AWAITING_THREAD]`) aren't ceremony; they're the discipline that makes the inversion safe.
