## Surprising thing for the next session

The **idle-only dispatcher** (#239) shifts the invariant of multi-bank stress tests. Previously a single bank with multiple credentials could process several jobs concurrently (one per credential or via batch); now banks are mutually exclusive on dispatch — bank A is busy → bank B gets the job → bank A finishes batch → eligible again. Tests like `test-multi-bank-stress.sh` and `test-multi-bank-stress-unique-amt.sh` will *behave differently* on shared-bank scenarios but still pass because they assert end-state (queue success), not throughput shape. If a future test wanted to assert "no double-dispatch within bank X within batch", it would be a brand-new assertion line item. Worth noting in case stress-test runtime behavior changes meaningfully.
