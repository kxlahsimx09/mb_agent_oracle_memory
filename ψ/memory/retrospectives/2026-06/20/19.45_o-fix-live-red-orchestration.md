## Lessons Learned
- **Pattern — premise-before-dispatch is non-negotiable.** A handoff's suggested fix can already be in the tree; the real bug is often one layer up. Read live HEAD first, every time.
- **Pattern — token rotation ≠ token expiry.** A mid-run 401 with a *future* `expiresAt` in `.credentials.json` = a rotation; stalled agents recover with a nudge (next turn re-reads creds). A full account `/login` kills them → re-spawn. Check the creds file before escalating.
- **Pattern — `maw team spawn --exec` recovery drops panes into the caller's window + cwd.** It inherits the account (good) but trips the orchestrator-guard (window_name) and lands in the wrong cwd. Salvage = `break-pane -n <role>-<campaign>` + drive with absolute paths; or prefer team-dispatch-helper if account-pinning isn't required.
- **Pattern — let independent agents disagree.** brew-ops's `audit_log` beat the investigator's code-trace on scb3. Route the ambiguous question to a *different* method, don't just trust the first verdict.
- **Pattern — an over-loaded assertion is a triage hazard.** FRD3's `crossOk` mixed isolation + completeness into one boolean with a static "wrong account" message → a dead bot masqueraded as a money-correctness leak and cost a full matcher audit. Split orthogonal properties; reserve RED for the real failure.
