This hook needs to distinguish the orchestrator from agents it dispatched.
- **Judgment**: the owner's instinct to redo on opus beat my efficiency argument; the security bug it caught justified the cost. Good reminder that for auth/security-critical surfaces, model tier is not where to economize.

## Lessons Learned
- **maw `fleet renumber` (and likely other mutating subcommands) execute on `--help`** — never probe them that way; read usage from the bare `maw <group>` listing. It also replaces FLEET_DIR symlinks with standalone files (decouples vault-sync) and renames live tmux sessions. (saved to Oracle learn)
- **maw default model is sonnet** — pass `--model opus` on every dispatch when the owner wants opus. (saved to Oracle learn + owner preference)
- **A 'dev-ready' backend can still be un-live-testable** for lack of an RLS-safe read surface — a plain Postgres view over an RLS table bypasses RLS unless `security_invoker=true`.
- **Test the layer the change lives in**: the backend tester (8/8) couldn't catch a UI-side MFA bug; opus reviewing the *code* did. Cross-layer contracts (UI AAL gating vs server AAL2 enforcement) need both a code review and a server-contract test.
- **Read window NAMES, not positions, before dispatching to a standing fleet** (`tmux list-windows -F '#{window_name}'`).
- **gh multi-account gotcha**: an invalid default account silently blocks everything even when a valid account is logged in; re-store the valid token to the active account (`gh auth token -u X | gh auth login --with-token`).
- **Vercel**: `env add` is guardrailed in this environment (returns guidance JSON) but `vercel deploy --build-env K=V` works for a one-off preview.
