## Lessons Learned
- **Append-only triggers (`tr_bankbot_activity_log_no_delete`) block bank-row deletes** — the "Nothing is Deleted" principle is SQL-enforced. To purge: owner sign-off + one atomic `DISABLE TRIGGER … DELETE … ENABLE TRIGGER` transaction (DDL is transactional → never left disabled) + a probe-DELETE re-verify that the guard is restored. Backup first.
- **A callback AMBER is not always a bug** — verify WHERE the callback was dispatched. Payout callbacks resolve `merchant_config.callback_url` (§ADR-9, deposit-gated COALESCE), not `client_callback_endpoints`; the harness must repoint the payout merchant. Refuted the prior "env flakiness" hypothesis with a controlled experiment (repoint flips 0/3→3/3).
- **"Built but never run" = a real coverage gap.** "NEW—LIVE" in a matrix can mean *designed*, not *certified-green*. Land the first GREEN baseline before building additions on top.
- **"Runs once" ≠ "ported completely."** A code-audit (bot-writer cross-repo vs current) catches dead-but-ported code (keepSessionAlive) the functional test passes right over.
- **Squash-stack merge order:** squashing the base PR creates a *new* commit; the dependent PR (carrying the base's original commits) then conflicts. Resolve by `git merge origin/main` into the dependent branch (non-force) — never rebase-force-push (AGENTS.md §9).
- **Dispatch by ORACLE NAME, not role-label** — `next-dev` is invalid; use `next-dev-1/2` (gateway) or **`nextbot-dev`** (bank-bot). The helper validates + rejects. (Matches the new [[orchestrator-dispatch-oracle-name-not-label]].)
- **Idle standby agents spam doorbells + burn quota** — a rigid "reply standing by" prompt makes it worse. Park them (kill process, `--keep-worktrees`), re-spawn on demand. The user's workspace need was the worktree, not a spinning agent.
- **Salvage a crashed agent:** work is often committed-unpushed OR uncommitted-on-disk, frequently already GREEN. Respawn into the kept worktree to *finalize* (commit + findings + PR), don't redo. The finish-script may "skip current window" and leave the process alive → kill by PID; `ps|grep agent-id` self-matches its own args (false positive) — filter `comm==claude`.
