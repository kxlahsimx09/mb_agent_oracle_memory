## Honest Feedback
- **The workflow works, and the proof was concrete.** The PROV 403 defect is the canonical "why de-bias matters" case — a structural reviewer pass + an independent ground-truth verify disagreed, and the verify was right. Worth citing forever.
- **My monitors were noisy.** Almost every Monitor fired its "PANE-GONE" on *my own* teammate kills (expected, but it cluttered the stream). I should have made monitors exclude the pane I was about to kill, or just leaned on doorbells (which were 100% reliable all session) + a single thin crash-watch. I over-armed.
- **I under-sized two timeouts** (the FLEET tester's 21-min window; the first PROV error-grep matched the agent's own command text). Both were self-correcting but avoidable — size watches to the work, and never grep an agent pane's *body* for error words (footer-only).
- **The status-audit staleness is the real systemic risk here.** A PM "refresh" audit confidently regressed built epics to build-pending four times. The fix is cultural: a status audit MUST ground in PRs+code+gates at HEAD, never in a prior audit's labels. I've saved this, but it should probably harden the next-pm SKILL.
- **I asked the owner a lot of AskUserQuestions.** Most were genuine forks, but toward the end I could have exercised more standing autonomy on the cheap finishes (the owner's "nudge"s were telling me to just go).
- **Doc-PR debt accumulated.** Marks live in owner-merge doc PRs (#612/#617/#621); they piled up un-merged. That's correct per §9a, but the owner now has a queue.

## Lessons Learned
- **Pattern — ground status in artifacts, not labels.** Re-derive every epic/story status from merged PRs + code at HEAD + gate evidence. Prior-audit labels (and even INDEX) drift; they over-reported build-pending 4× this session.
- **Pattern — EF authz reads the static `_shared/rbac.ts` map, not `role_permissions` DB.** Seeding the DB is necessary-but-insufficient; the perm must be in the static map (+ config.toml verify_jwt=false + a positive-authz self-test). Caught the PROV 403; pre-empted DTR/FLEET.
- **Pattern — LIVE-gate N/A for non-money.** The §ADR-21 money journey has nothing to exercise on a read-only/admin-config surface → epic-DONE rests on gates 1-4. Owner-set (CLIREAD #611), applied to PROV/MDRWRITE/OTPLOG/FLEET/BENE.
- **Pattern — dev↔tester de-bias via separate slugs.** Spawning the tester under its own campaign slug (own worktree) keeps it from reading dev code; binds to the SPEC via `git show`.
- **Anti-pattern — re-using a finished campaign slug** (tangles the half-removed worktree/branch). Fresh slug per new piece.
- **Op-tip — a degraded teammate session that swallows `maw team send` as keepalives → kill + re-spawn clean** (the re-spawn opened the PR first try).
