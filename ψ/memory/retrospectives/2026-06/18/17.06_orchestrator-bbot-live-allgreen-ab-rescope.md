## Lessons Learned
- **Pattern — verify before coding a "bug":** never dispatch a code fix on one agent's verdict; have the *implementer* prove it against the sealed spec first. An investigator can be confidently wrong.
- **Pattern — orchestrator gets ground truth directly:** when two agents talk past each other on a deploy/DB fact, a direct Mgmt-API query settles it faster than another agent round-trip. A "function-local variable" is not a "relation"; a code "is it deployed" check must read the *function source*, not a sentinel object.
- **Pattern — current production is the source of truth for re-scope decisions:** the next-system doc (§2) said resend/cancel were "client front-door"; the real Go gateway + next EFs showed cancel/resend use the gotrue actor-matrix (`adminAuth`), and client payout-cancel was deliberately removed. Check the code, not the claim.
- **Gotcha — squash-merge breaks stacked-PR auto-retarget:** GitHub leaves the base PR's commits "duplicated"; fix with **merge-main-in (not rebase)** to stay inside the no-force-push rule; resolve the superseded-superset conflicts `--ours`.
- **Gotcha — `ts_payouts.failure_code` is NULL by design for sweep-cancels;** the distinct cancel code lives in the `payout.cancelled` callback payload (§ADR-9). Assert the *path*, not the column.
- **Mechanic — spawn fleet agents into their OWN window, not a split:** `maw team spawn <team> <role>` *without* `--exec` prints the `claude …` Run command; `tmux new-window -d -n <role> -P` + send-keys it there. Deliver the task kickoff via send-keys after boot (the `--exec`/`--prompt` kickoff races boot and is lost). Close idle agents immediately (`tmux kill-pane` + `maw team cleanup --zombie-agents`).
