## Lessons Learned
- **Pattern — seal/verify must re-derive from ground truth, never trust the harness flag.** Two real bugs (returning-user login, M4 inversion) were invisible to happy-path tests because those minted bearers / re-cancelled directly. The independent, code-level-proof re-derivation is the whole value.
- **Pattern — fan-out by FILE, not just by item number.** Architect+writer both editing the same docs (identical bytes) cost a deconflict. Give each parallel owner a disjoint file allow-list.
- **Pattern — the dominant flow is the journey.** A golden journey through the minority path (slip) verifies less than the majority path (statement auto-match). Scope the LIVE journey to where the real money flows.
- **Anti-pattern — `[RATIFICATION_PENDING]`/spec authored before story ratify** silently ships the opposite of the decision (DEPOSIT-010). binding_sources citing a stale AC-count is the tell.
- **Ops — `maw team spawn` + orchestrator-guard:** spawn lands in the orchestrator's tmux window → guard mis-fires; `tmux break-pane -d -s <pane> -n <role>-work` right after spawn fixes it. `--exec` doesn't auto-submit; nudge with `send-keys -l + Enter`. (Memory `maw-spawn-guard-misfire-breakpane`.)
- **Ops — vanity subdomain ≠ custom domain:** it does not rewrite the gotrue JWT `iss`, so it cannot replace a custom domain for any iss-pinning EF. (Memory learning 2026-06-10.)
