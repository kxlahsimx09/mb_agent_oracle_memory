## Lessons Learned
- **Pattern — ground-truth over pane-scraping**: for dispatched maw teammates, poll git/PR/Management-API/evidence-JSON, never the spinner-flooded TUI. Keyword watchers on panes false-positive on echoed prompt text; exclude your own message strings.
- **Pattern — orchestrator routes, never arbitrates**: dev's EF-placement + ADR-supersession flags went to the reviewer for an ADR-consistency ruling; ack the dev to unblock but don't decide the technical call yourself.
- **Pattern — de-bias VERIFY earns its keep**: a code-blind tester caught a real verify_jwt deploy-config gap (008) and correctly classified probe-bugs vs substrate (009 AC10, 010 AC4) without false alarms.
- **Pattern — premise-check-first**: every slice was 90–95% pre-built; the genuine delta was small (a perm rename, a config line, one new EF+RPC). Verify each AC vs live HEAD before writing.
- **Pattern — verify_jwt platform-gate is a recurring class**: admin/self-auth EFs need `verify_jwt=false` in config.toml or the platform 401s the stub bearer before the EF's own auth runs. Dev now pre-empts it.
- **Anti-pattern — uncommitted evidence**: dep12's evidence JSON sat in the primary repo (untracked) and never got committed to the test branch before finish removed the worktree. Nudge-to-commit must land before cleanup.
- **Pattern — re-spawn is cheap**: a teammate pane dying mid-task loses warm context only; branches + committed findings persist (008 tester re-spawn).
