## Lessons learned (for the vault)
- A tri-epic LIVE run that bypasses the real bank-bot+portal proves the gateway, not the intake seam — state it as an honest-limit, and for a full-topology sign-off route deposits via `/sim/inject` → real ECS bot → bot-statements (the bbot-journey path), not the harness-as-bot shortcut.

- Epic-seal that probes only the auto path can miss a manual-path ledger defect (D-1) — live recount is complementary teeth.
