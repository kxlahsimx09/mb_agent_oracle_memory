## Honest Feedback
- **What worked:** The dispatch-verify-merge discipline held across ~20 PRs with zero reused other-team agents and every teammate closed on idle. The adversarial investigator step earned its cost twice over. Pausing mid-program for genuine money/compliance decisions (rather than barrelling) matched the owner's clearly hands-on style. The gist-for-complex-decisions habit fit how this owner wants to decide.
- **What was clumsy:** (1) The PR#83 hold race — a hold instruction sent *after* dispatch can lose to a reviewer's auto-merge; holds must be set at dispatch time. (2) I over-narrated some turns; on a doorbell-driven marathon, tighter status would have served better. (3) ADR numbering collided (two ADR-36s on different branches) because parallel architects each grabbed the next number — needs a numbering lock. (4) I twice had to re-verify "done" claims against actual code (PM marked direct-transfer done when it was still mock; a tester used stale cached creds) — trusting agent self-reports over ground truth would have corrupted the tracker.
- **Process risk:** This program touched a *live* stack (sinuw) with a concurrent unknown operator. brew-ops correctly refused to race it. The right instinct, but it shows multi-actor coordination on shared live stacks is fragile and under-tooled.

## Lessons Learned
- **Pattern — parity is not a single axis:** "match current" can mean *add* safety or *remove* it. Always diff against ratified internal decisions and surface the conflict to the owner.
- **Pattern — single-source-of-truth beats dual-write discipline:** the RBAC drift question proved that two authorities (code map + table) drift no matter the convention; collapsing to one (DB) + a DB-side safety floor was cleaner than a drift-guard test.
- **Pattern — adversarial verify before merge on money/security:** the investigator found real bypasses tester GREEN missed (TRUNCATE skips BEFORE-ROW triggers; no-approval-gate money path).
- **Pitfall — `maw team send` does not wake an idle teammate:** use a direct `tmux send-keys` nudge (capture-pane before/after to confirm submit).
- **Pitfall — a "hold" sent after dispatch races the reviewer's auto-merge:** set merge-gates at dispatch time, not after.
- **Pitfall — verify "done" against code, not agent self-reports** (a PM false-marked direct-transfer; a tester used rotated/cached creds).
- **Pattern — owner-gated live actions:** never auto-run identity/legal/prod-money mutations; hand off (sinuw cutover) or fetch+confirm (verbatim terms text via brew-ops prod access).
