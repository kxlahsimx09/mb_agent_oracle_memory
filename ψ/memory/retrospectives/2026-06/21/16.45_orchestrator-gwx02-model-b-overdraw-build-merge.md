## Lessons Learned
- **Pattern**: Reserve-at-claim collapses in-flight accounting into the reservation — when over-draw spans an async claim→settle window, decrement (reserve) at claim, not at settle; settle becomes a no-op, scrape reconciles. (Avoids a separate cross-batch in-flight pass.)
- **Pattern**: A bot-supplied timestamp that load-bears a freshness guard MUST be clamped to the server clock (`LEAST(bot_ts, app_now())`) or it's a guard bypass.
- **Anti-pattern**: Build agents cutting branches from a stale mental baseline → "green" self-tests against a base that doesn't match trunk. Always rebase + re-read the *current* signature of the function under change before writing a DROP/CREATE migration.
- **Anti-pattern**: Doc agents creating "new" files that already exist on main (parity register) → add/add merge conflicts. Always `git fetch origin && diff origin/main` before authoring.
- **Pattern**: Deploy is single-owner (brew-ops) and structurally guarded; route the envelope to `for-brew-ops/`, don't bypass. Don't drive another agent's TUI that has unsent input.
