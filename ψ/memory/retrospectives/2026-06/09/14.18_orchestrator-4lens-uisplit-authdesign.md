## Lessons Learned
- **Pattern — the next-ui 4th lens earns its seat.** It caught what the 3 backend lenses structurally couldn't: console-surface gaps (5 HIGH wallet UI stories) and a missing read/query API that made a "dev-ready" deposit epic un-live-testable. A backend-only review declares victory too early.
- **Pattern — dpay-verify via a fresh teammate, grounded in Go first.** Direct `mcp__dpay__*` from a fresh brew-ops session (NOT the flaky dpay-finder subagent; NOT the long-lived orchestrator session whose dpay HTTP session expires). Verify-don't-assume caught a decoy collection (`wallet_change_logs` singular = 4 test docs vs the live `wallets_change_logs` = 4.67M).
- **Pattern — adr.md multi-PR cascade.** Several ADR PRs touching one file re-conflict as each merges. Resolve with MERGE (not rebase → no force-push); most are clean unions of additive amendment blocks; the non-union case (a shared header that moved) needs the owning agent. PRs touching DIFFERENT §ADR sections don't re-conflict each other → can merge freely once re-synced.
- **Pattern — no-shim auth cutover.** Owner chose to delete the stub + re-mint sealed-slice probes onto real gotrue JWTs in one change (zero bypass surface) over a temporary dual-accept compat shim. The re-mint is "not extra work" — it's the SIM-LIVE login leg anyway.
- **Pattern — orchestrator-guard discipline.** Orchestrator does integration/coordination + clean mechanical resolution; dispatch the owning agent for any judgment edit to source/docs/SKILLs. ψ vault + /tmp + inbox are the orchestrator's write zones.
- **Anti-pattern avoided — inline UI/substrate markers.** Started down a per-story Kind tag; the user's "separate docs entirely" instinct was cleaner — the document a story lives in IS its kind.

The polling overhead was real — I wrote many background `git log`/file-exists poll loops, and several mis-fired (a bash glob typo, a false-positive marker grep, a stale "BOTH DONE"). Overall: high-quality, well-grounded output (every decision traceable to ADR/dpay), at a cost the user explicitly opted into.
