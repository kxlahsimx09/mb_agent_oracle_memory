## Lessons Learned
- **Pattern — relay-not-decide propagates down the whole chain**: next-writer escalated the money-gap to the architect instead of deciding; the architect routed AF4 to the user instead of self-binding; I routed the §ADR-12 amendment + AF4 to the user. The discipline held at every level and every money/ratified-ADR call landed with the right authority.
- **Pattern — a "faithfulness doc-fix" can be a ratified-ADR change in disguise**: "settlement is UI not API" looked like a one-line doc edit but contradicted the ratified §ADR-12 D1 caller taxonomy → architect amendment + user ratification (the #236 path). Always check whether a fix touches a ratified ADR before treating it as writer work.
- **Gotcha — committed ≠ deployed**: PR #108 merged ~09:50 but the running `~/.claude/hooks/` copy stayed the stale whole-dir gate until the 15:41 redeploy. The recurring false-blocks were deploy-lag, not a merge gap. For any daemon/hook change, confirm the DEPLOY (install script re-run + byte-identical check), not just the merge.
- **Gotcha — stale-state-on-resume bit twice**: in a long multi-wake session, my memory of "what other sessions did since" is untrustworthy; the thread API + delegating adjudication to the owner are the only reliable corrections. Tag: `stale-state-on-resume`.
- **Pattern — hold the line on sibling-owned envelopes**: corrupting another campaign's audit trail (or rendering its architectural verdict) to clear a buggy gate is worse than absorbing the false-block. The circuit-breaker + the owner clearing it are the safe outlets.
- **Pattern — surface PRs before merge**: the user caught the R1 over-generalization only because PR #261 was surfaced for review pre-merge; it would otherwise have baked a wrong scope into the requirement surface.
- **Pattern — delegate footprint retirement to brew-ops, never inline**: applied the prior retro's #1 lesson directly — dispatched #252 rather than running `git worktree remove`/`maw sleep` myself, with an explicit mine-only scope + hard don't-touch list (wt-22 #231/#232 active).
