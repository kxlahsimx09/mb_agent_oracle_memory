## Honest Feedback

- **The W9 spec's threshold heuristic is too coarse for perf-rewrite ranges.** When the range is dominated by single-line in-place rewrites (regex → equality, `$ne` → `=`), a 10-flow intersection is genuinely 10× hash-bump work, not 10× drift triage. The "split the pass" recommendation reads like over-caution in this regime. A useful refinement would be a per-class effort estimate before the threshold check fires — e.g., if 80%+ of touched-file diffs are pure single-line equality changes, allow the pass to proceed at a higher threshold (10 or 15 flows) since each pointer is mechanical.
- **The fast-fix vs full-pass call is similar to W2's: when in doubt, defer.** Today's call was to defer 8 flows rather than mishandle line shifts. Probably right — controller/service line shifts in dc9f7d8 are non-trivial (DepositController +21 lines, callbackService +69 lines), and a wrong Class A bump on a shifted-line pointer is a silent lie. Better one careful deferred pass than a sloppy full pass.
