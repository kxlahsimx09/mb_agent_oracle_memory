V1 lookup design crystallized over 3 sub-pivots:
- Pivot 1 (drop fallback): user noted §ADR-4b amendment B7 enforces match_hash → fallback's purpose (backfill) doesn't apply
- Pivot 2 (M4 sort): user pushed on collision realism; M4 emerged as clean structural mitigation (not score-threshold patch)

Decision diagram drawing helped both me and user converge on shared understanding. After diagram, user surfaced 2 simplifications quickly. Lesson: when explaining flow with 3+ branching paths, draw the diagram first, then discuss; saves ~50% of clarification cycles.
