## Scope = 2 front-door EFs + their RPCs (both RPC and EF are missing)

### AUTH-010 — rotate / revoke a CLIENT's own API key (self-service)
- **Cast (journey I.7):** "U-C1A rotates **C1's own** key" — this is the **client tier**, self-service on the client's own API credential (the key clients sign requests with), NOT an admin action on someone else.
- **Acceptance (journey I.7 + B.3 mirror):** new key works **immediately**; old key works for the **two-slot overlap** then dies; **revoke → immediate 401**; **secret shown once**; both rotate + revoke **audited**, scoped to the one client.
- **Build:**
  1. **RPC** `rotate_client_credential` + `revoke_client_credential` — **mirror the existing `rotate_bot_credential` / `revoke_bot_credential`** (two-slot overlap K1 + immediate-revoke K2, encrypted at rest with the client cred enc key, `write_audit_log`, secret returned once). The bot versions are the proven template — port minus the `bank_account_id` binding, plus the client/owner binding.
  2. **EF** (e.g. `client-key-rotate`) — front door auth = the **client-tier gotrue session / owner context** (NOT `adminAuth`; this is self-service on own key). `verify_jwt=false` + EF-side verify, like the other bot/auth EFs. Returns the new key+secret once.

### AUTH-011 — assign / change a user's role (single-valued)
- **Cast (journey I.7):** "U-SA changes a user's role" — **super-admin** action.
- **Acceptance:** **single-valued** (replace-not-add); effect on the **next request, no re-login**; **deleting a role still held is BLOCKED** (deny-with-count, matching admin-portal WUI-006 #26 + the delete-blocked-while-held #31).
- **Build:**
  1. **RPC** `admin_set_user_role` — single-valued replace; the delete-while-held BLOCK; emit `write_audit_log`.
  2. **EF** `admin-users-set-role` (or `admin-roles-assign`) — **mirror `admin-users-disable`** exactly: `verify_jwt=false`; `adminAuth(req)` → actor; `requirePermission(actor, "<perm>")` (role:assign or user:update — architect to settle the catalogue perm); `service.rpc("admin_set_user_role", …)`; map RPC RAISE tokens → status (404 unknown_user, 409/422 for the held-role block, etc.). The `admin-users-disable/enable/unlock/reset-2fa` family is the byte-for-byte EF template.
