## EXACT WUI-008 CONTRACT (for next-ui to wire the create flow)
**EF name:** `admin-clients-create` → `POST /functions/v1/admin-clients-create` (verify_jwt=false, EF-side gotrue verify, AAL2 admin JWT).

**Request body (JSON):**
| field | req? | notes |
|---|---|---|
| `client_name` | YES | non-blank |
| `username` | YES | the §ADR-2 identity handle; must be unique on app_user |
| `password` | YES | gotrue login password |
| `merchant_id` | YES | FK → merchant_config; must resolve |
| `parent_client_id` | no | **the sub-client parent picker** — present ⇒ provisions a SUB-CLIENT (gates on `sub-client:create`); absent ⇒ top-level client (gates on `client:create`). Must resolve to an active client. |
| `email` | no | gotrue login email (defaults to `<username>@clients.local`) |
| `pool_id` | no | NULL ⇒ inherit merchant's pool |
| `mdr_profile_id` | no | NULL ⇒ inherit merchant's MDR profile |
| `enable_deposit` / `enable_payout` / `enable_topup` / `enable_settlement` | no | **b1 default-OFF**: only an explicit JSON `true` enables a flow; anything else ⇒ false. A new client cannot transact until an admin enables a flow. |
| `min_payout` / `max_payout` | no | bands; 0 = unlimited; min>max (non-zero) ⇒ 422 |

**Success — 201 Created:**
```json
{ "provisioned": true, "client_id": "<uuid>", "user_id": "<gotrue sub = app_user.id>",
  "user_type": "client" | "sub-client",
  "api_key": "pk_…", "api_key_secret": "sk_…",   // §ADR-7 creds — SHOWN ONCE, never retrievable again
  "status": "active" }
```
The `user_id` is the value EVERY lifecycle EF (set-role / disable / enable / unlock / reset-2fa) takes as its `user_id`, and the row v_users surfaces. Show `api_key_secret` once (PROV-001 "shown once at creation time").

**Errors (honest 4xx — the portal must NOT mark done on 4xx):**
- 400: `missing_client_name` / `missing_username` / `missing_password` / `missing_merchant_id`
- 401: missing/bad/AAL1 JWT
- 403: non-admin tier OR missing the perm (`client:create` / `sub-client:create`) — `{error:"forbidden", required_permission}`
- 404: `unknown_merchant` / `unknown_parent_client` / `unknown_pool` / `unknown_mdr_profile`
- 422: `invalid_band` (min_payout > max_payout, max≠0)
- 409: `username_taken` / `api_key_collision` / `email_taken` / `identity_mint_failed`
