# PR #427 (`94e0c1a`, 2026-05-08) added a new external-cron-driven Telegram wallet

PR #427 (`94e0c1a`, 2026-05-08) added a new external-cron-driven Telegram wallet alert. Endpoint: `POST /api/v1/telegram/wallet-alert/high-balance` — bot-secret protected per-route (`BotAuthMiddleware()`), notably the only bot-auth route that lives outside the `/api/v1/bot` group. Behaviour: scan active client wallets (`owner_type:"client"` + `status:1`) above `WALLET_HIGH_BALANCE_THRESHOLD` env (default 200,000 THB, kept in sync with `front-end/src/components/HighBalanceAlert.tsx` per controller comment), publish ONE summary Markdown message listing every offender (sorted by balance desc) to a new `wallet_alert` channel-type ("แจ้งเตือน Wallet" room) — single-message shape is load-bearing because Telegram rate-limits at ~30 msg/sec/chat and ops occasionally see 30+ candidates in one cycle. Idempotency: SHA-1 hash of `(client_name, balance ÷ 50_000 bucket)` across the result set is stored at Redis key `wallet_alert:high_balance:last_hash`; firing within `highBalanceForceWindow=23h` with the same hash returns `sent:false, reason:"unchanged since last alert"`. Bucketing dampens churn (251k↔252k = same state). After 23h we resend so the channel gets at least one daily heartbeat. Redis errors fail OPEN (always send). Read replica path; 30s context timeout. Pre-deploy: insert the channel record with `channel_type="wallet_alert"` into `telegram_configs.channels[]` via the existing `POST /api/v1/telegram-config/:id/channels` admin endpoint, otherwise delivery silently fails with `no active channel found for type: wallet_alert`. Service-side additions: `services.ChannelTypeWalletAlert`, `services.HighBalanceItem{ClientName, MerchantName, Balance}`, `services.SendWalletAlertNotification`, `services.SendHighBalanceAlert(items, threshold)`. Both client name and merchant name are `escapeMD`-escaped before formatting (legacy Markdown). Threshold env: `WALLET_HIGH_BALANCE_THRESHOLD` set in `k8s/configmap.yaml` (out-of-territory but worth noting).
