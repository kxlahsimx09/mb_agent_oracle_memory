# Announcements API added (`2f35356` #455, 2026-05-22) — admin posts news/banner e

Announcements API added (`2f35356` #455, 2026-05-22) — admin posts news/banner entries from `/setting/general`; any authenticated user (client/partner/merchant/sub-client) reads via `GET /api/v1/announcements/active` to render above HighBalanceAlert on `/wallet`. New collection `announcements` (model: `models/announcement.go`) with bilingual `title_th`/`title_en`/`content_th`/`content_en`, integer `priority` (higher first), `published_at` + nullable `*primitive.DateTime` `expires_at` for pre-schedule + auto-hide, `status` 1=Active/0=Inactive (project's universal entity convention), `created_by`/`updated_by` populated from JWT username. Six endpoints under `/api/v1/announcements` group, all JWT-required; **admin gating uses `user_type=="admin"` checked inside each handler** (same lightweight pattern as `isAdminWithForceApprove`) rather than a dedicated RBAC resource — write paths return 403 for non-admin, `GET /active` is open to any authenticated user. `GET /active` filter: `status:1 AND published_at<=now AND (expires_at missing/null OR >now)`, sort `priority DESC, published_at DESC`, `SetLimit(20)`. `POST /` requires at least one non-empty title (`title_th` or `title_en`) and SSE-publishes `announcements/created`; `PUT /:id` uses all-pointer input for partial updates, `expires_at<=0` is the "clear" sentinel (`$unset`); `DELETE /:id` publishes `announcements/deleted`. List endpoint supports pagination + status filter + free-text search across `title_th`/`title_en` via case-insensitive regex. Reads use `db.GetReadCollection` (read replica), writes use `db.GetCollection` (primary). Route wired in `main.go:405-408` between `SetupBankStatementRoutes` and `ClientAPIRoutes`.
