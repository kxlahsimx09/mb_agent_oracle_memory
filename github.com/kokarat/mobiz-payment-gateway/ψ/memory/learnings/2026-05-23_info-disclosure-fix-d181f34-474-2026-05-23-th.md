# Info-disclosure fix (d181f34 #474, 2026-05-23): the IDEMPOTENCY_KEY_REQUIRED 400

Info-disclosure fix (d181f34 #474, 2026-05-23): the IDEMPOTENCY_KEY_REQUIRED 400 response on POST /api/v1/deposit/create and POST /api/v1/payout/create dropped its docs_url field, which had been hard-coding the URL https://github.com/kokarat/mobiz-payment-gateway/blob/main/docs/idempotency-api-spec.md — leaking the internal GitHub repo path to every API client that omitted the X-Idempotency-Key header. Reported by an integration partner. Both controllers' 400 body is now exactly {status:"error", code:"IDEMPOTENCY_KEY_REQUIRED", message:"X-Idempotency-Key header is required for this endpoint"}. The docs_url was introduced by the Idempotency v2 PR (#392, 15a54a4, same day) and removed two commits later. The full client contract still lives in docs/idempotency-api-spec.md; only the in-response link was removed, and a public (non-repo) docs URL can be re-added later without leaking source location. Documented in current-system.md §3.3 idempotency-v2 entry; the prior docs_url wording is marked SUPERSEDED per P-001 rather than deleted. This was the single new in-territory commit covered by the W2 amend extending PR #457 (cumulative c7b2232..d181f34); the 5 feature commits before it (idempotency-v2, announcements API, Thunder slip-verify deferral, deposit floor-to-baht, brand multi-tenancy) were already documented by prior amends of the same PR.
